# Ishan Lath — Resume Website

A simple, responsive personal resume website built with HTML5 and CSS3.

## Files
- `index.html` — page structure and resume content
- `style.css` — colours, typography, layout, responsive rules
- `assignment-notes.pdf` — short explanation of the design and CSS choices

## Preview locally
Open `index.html` in a browser. Keep `index.html` and `style.css` in the same folder.

## Publish with GitHub Pages
1. Create a GitHub account at https://github.com/ if you do not already have one.
2. Create a new **public** repository named `ishan-resume-website`.
3. Upload `index.html` and `style.css` to the repository's root folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the Pages URL to appear. It will usually look like:
   `https://YOUR-GITHUB-USERNAME.github.io/ishan-resume-website/`

## Before submitting
- `profile.jpg` is the profile photograph used by the website. Keep it in the same folder as `index.html`.
- Check that the B.Com and IIMB programme descriptions reflect your exact current enrolment/status.
- Add specific operational responsibilities from your father's business only if you can accurately describe them.
- Test the website on both desktop and mobile.
- Add your final live website URL and repository URL to the submission.
